## Самый маленький шаблон

Шаблон pavlus — это текстовый файл, обычно с именем `something.pavlus`. Каждая строка — одна вещь: элемент, кусок текста или ключевое слово. **Отступ** определяет, что внутри чего, как в Python или YAML. Нет закрывающих тегов и нет фигурных скобок вокруг блоков.

Самый маленький полезный шаблон — одна строка: имя тега и его текст.

::demo hello

Демо выше компилируется настоящим компилятором прямо сейчас, в вашем браузере. Вы видите шаблон, HTML, который произвёл `render`, и ниже модуль, сгенерированный компилятором. Раскрывайте свёрнутые разделы, если интересно; остальная часть этой страницы использует только первые два.

> [!TIP] Пробелы, а не табуляция
> Делайте отступ двумя пробелами. Строка с отступом больше предыдущей становится её дочерней; строка с меньшим отступом завершает блок.

## Классы и id

После имени тега можно добавить классы через точку и id через решётку, в том же порядке, в каком вы писали бы CSS-селектор. Имя тега можно опустить: `.card` означает `div.card`.

::demo selectors

Несколько классов цепляются подряд: `a.btn.btn-primary`. Без тега элемент — это `div`, поэтому `#app` — это `<div id="app">`.

## Текст

Текст после тега, на той же строке, — первый дочерний узел элемента. Для более длинного или смешанного содержимого помещайте текст на отдельные строки, начинающиеся с вертикальной черты `|`. Каждая строка с `|` — это один текстовый узел, и текст может содержать `{expressions}` (см. следующую страницу).

::demo text-lines

Строка, начинающаяся с `//`, — комментарий. Он никогда не попадает в результат.

## Атрибуты

Атрибуты пишутся в скобках после тега, через пробелы. Значение может быть строкой в кавычках, литералом, похожим на число, или выражением.

::demo attributes

- `type="button"` — обычная строка.
- `disabled` без значения — булев атрибут: он присутствует и означает *true*.
- `href=url` без кавычек, поэтому `url` — это **выражение**: оно читает поле `url` из state.
- `title="Open {name}"` — строка с «дыркой» внутри; компилятор превращает её в конкатенацию.

> [!NOTE] Кавычки определяют, чем является значение
> `class="x"` — это текст `x`. `class=x` — это поле state `x`. Это самая частая первая ошибка, и компилятор не может о ней предупредить, потому что обе формы корректны.

## Переключение класса

Статический класс записывается через точку. Класс, который зависит от state, записывается как атрибут с именем `class:name` и условием в качестве значения. Класс есть у элемента, когда условие истинно.

::demo class-toggle

Обратите внимание на второй шаг демо: изменяется только атрибут `class`, больше ничего. Как компилятор узнаёт, что менять, — тема [раздела о компиляторе](page:compiler-diff).

Раздел AST показывает для каждого узла ту часть state, которую он читает. Узлы с *reads: none* не могут измениться никогда, поэтому сгенерированный `diff` пропускает их целиком.

## Что вы узнали

- Строка — это элемент: `tag.class#id(attr=value) text`.
- Отступ — это вложенность. Начальный `|` создаёт строку текста. `//` создаёт комментарий.
- Значения в кавычках — это текст, значения без кавычек — выражения, `class:name=cond` переключает класс.
