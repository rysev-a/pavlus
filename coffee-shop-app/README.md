# Coffee shop CRM

A [pavlus-server](../server) app. It was **generated by Flow Studio** from the design
of the same name: the pure handlers are `server/modules/`, the routes `server/routes.ts`,
the wiring `server/main.ts`, the tables `server/schema.sql` and their starting rows `server/seed.ts`.
The design is the source: change it in Flow Studio and generate again
(`node ui-kit/scripts/flow-generate.ts <demo> <folder>`).

```sh
cp .env.example .env && npm run db:up   # Postgres on port 54330
npm start                          # http://127.0.0.1:3020
npm test
```

## Routes

- `GET /customers`
- `POST /customers`
- `GET /menu`
- `GET /orders`
- `POST /orders`
- `PATCH /orders/:id`
- `GET /dashboard`

## Plugins of the design

- `server/plugins/mailer.ts`: sends the receipts of the orders (a stub: replace the TODOs with the real client)
