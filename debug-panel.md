# chrome extention

Need to create chrome extention with debug info for pavlus

## effects

- show history of all effects, also with tabs, when you can select "all" or select some plugin

- for all effect show message delay (for example how log was dom rerender or http request)

## messages

- show history of all messages

## applications filter

- show svg hierarchy of application, also can select some application and see only message and effects of this application

## store

- show store and all store content
- show timeline of history changes, also we save all statge changes by restore, and we can navigate by timeline and see all application changes - step back, step forward
