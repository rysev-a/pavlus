## 最小的模板

pavlus 模板是一个文本文件，通常命名为 `something.pavlus`。每一行是一件事：一个元素、一段文本，或一个关键字。**缩进**说明谁在谁的里面，和 Python 或 YAML 一样。没有结束标签，代码块周围也没有花括号。

最小而有用的模板只有一行：一个标签名，后面跟着它的文本。

::demo hello

上面的 demo 此刻正由真实的编译器在你的浏览器里编译。你可以看到模板、`render` 生成的 HTML，以及再往下，编译器生成的模块。好奇时可以展开折叠的部分；本页其余内容只用到前两项。

> [!TIP] 用空格，不用 Tab
> 用两个空格缩进。比上一行缩进更多的行成为它的子节点；缩进更少的行则结束这个块。

## class 和 id

标签名之后，你可以用点添加 class，用井号添加 id，顺序和写 CSS 选择器时一样。标签名可以省略：`.card` 表示 `div.card`。

::demo selectors

多个 class 可以串联：`a.btn.btn-primary`。没有标签时元素是 `div`，所以 `#app` 就是 `<div id="app">`。

## 文本

标签之后、同一行上的文本，是元素的第一个子节点。对于较长或混合的内容，把文本放在以竖线 `|` 开头的单独行中。每个 `|` 行是一个文本节点，文本里可以包含 `{expressions}`（见下一页）。

::demo text-lines

以 `//` 开头的行是注释。它永远不会出现在输出中。

## 属性

属性写在标签后面的括号里，用空格分隔。值可以是带引号的字符串、类似数字的字面量，或者表达式。

::demo attributes

- `type="button"` 是普通字符串。
- 不带值的 `disabled` 是布尔属性：它存在，意思是 *true*。
- `href=url` 没有引号，所以 `url` 是**一个表达式**：它读取 state 的字段 `url`。
- `title="Open {name}"` 是中间有个洞的字符串；编译器把它变成一次拼接。

> [!NOTE] 引号决定值是什么
> `class="x"` 是文本 `x`。`class=x` 是 state 字段 `x`。这是最常见的初学者错误，编译器无法对它发出警告，因为两种写法都是合法的。

## 切换 class

静态 class 用点来写。依赖 state 的 class 则写成名为 `class:name` 的属性，并用一个条件作为它的值。当条件为真时，该 class 就在元素上。

::demo class-toggle

注意 demo 的第二步：只有 `class` 属性被打了 patch，其他都没动。编译器如何知道该给什么打 patch，是 [编译器部分](page:compiler-diff) 的主题。

## 你学到了什么

- 一行就是一个元素：`tag.class#id(attr=value) text`。
- 缩进就是嵌套。开头的 `|` 表示一行文本。`//` 表示注释。
- 带引号的值是文本，不带引号的值是表达式，`class:name=cond` 用来切换 class。
