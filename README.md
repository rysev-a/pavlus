# pavlus

Two packages in one npm workspace:

| Directory                   | What                                                                                                                                                                                  | Docs                                         |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| [`framework/`](./framework) | **pavlus**, the framework: pure application code, side effects in plugins, templates compiled to pure `render`/`diff`. Published to JSR as `@service-laboratory/pavlus`.              | [framework/README.md](./framework/README.md) |
| [`admin-app/`](./admin-app) | A full-stack admin dashboard built on pavlus: a static Vite frontend and a plain `node:http` backend serving JSON from Postgres.                                                      | [admin-app/README.md](./admin-app/README.md) |
| [`docs/`](./docs)           | The documentation landing page (generated by the real compiler): [docs/site/index.html](./docs/site/index.html), rebuild with `npm run docs:build`; SVG diagrams in `docs/diagrams/`. | [docs/site/README.md](./docs/site/README.md) |

The app depends on the framework by its package name
(`@service-laboratory/pavlus`); npm links it to `framework/` inside the
workspace, so the app is written exactly like one that installed the package.

## Quick start

```sh
npm install                          # both packages, once, from here

# framework
npm test --workspace framework
npm run publish:dry --workspace framework

# admin-app (needs Docker for Postgres)
cd admin-app
docker compose up -d                 # Postgres on :5432
npm run db:init                      # tables + demo data
npm run dev                          # API on :3000, frontend on :5173
```

Root scripts: `npm test` and `npm run typecheck` run in both packages,
`npm run format` runs Prettier over every `.ts` file (the same formatting Zed
applies on save).
