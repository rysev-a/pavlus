# pavlus

One npm workspace, two halves:

```
framework/     the framework, published as @pavlus/*
  core/        @pavlus/core      the isomorphic heart: Message/Effect/Plugin, createApp,
                                 toHandler, the pure store changes (applyChange, getIn)
  frontend/    @pavlus/frontend  DOM plugins, the template compiler, the vite plugin,
                                 SSR — everything a browser app needs (depends on core)
  backend/     @pavlus/backend   the server runtime: per-request flows, http/ws/pg/redis
                                 plugins, the pages plugin, class controllers (depends on core)
  ui-kit/      @pavlus/ui-kit    every shadcn component as a pavlus template
  debug-panel/                   the devtools panel + agents (in-repo, not published)
  editors/                       zed extension + tree-sitter grammar
  docs/                          framework docs (architecture, plugins, routing)

applications/  the apps that exercise the framework
  admin/           the reference full-stack app (pavlus frontend + node:http backend)
  visual-design/   the visual programming app (Flow Studio + Visual Builder)
  phone-crm/       the phone CRM frontend
  coffee-shop/     the coffee shop backend (scenario modules)
  social-network/  the social network frontend

docs/          the documentation site (generated by the real compiler):
               docs/site/index.html, rebuild with `npm run docs:build`
```

The packages depend on each other by name (`@pavlus/frontend` depends on
`@pavlus/core`, apps depend on `@pavlus/frontend` and `@pavlus/backend`);
npm links them inside the workspace, so an app is written exactly like one
that installed the packages. The JSR name of the frontend package stays
`@service-laboratory/pavlus`.

## Quick start

```sh
npm install                              # every package, once, from here

# framework
npm test --workspace @pavlus/frontend
npm test --workspace @pavlus/backend

# admin (needs Docker for Postgres)
cd applications/admin
docker compose up -d                     # Postgres on :5432
npm run db:init                          # tables + demo data
npm run dev                              # SSR + API on :3000, Vite hot reload

# the shop API example (backend framework, raw sockets or node:http)
cd framework/backend
docker compose -f examples/shop-api/compose.yaml up -d
npm run example:shop                     # http://127.0.0.1:3001
```

Root scripts: `npm test` and `npm run typecheck` run in every workspace,
`npm run format` runs Biome over every `.ts` file (the same formatting Zed
applies on save).
